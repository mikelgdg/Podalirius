# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please do **not** open a public issue.

Instead, report it privately by emailing the maintainers at **[TBD]**.

We will acknowledge receipt within 48 hours and aim to provide a fix timeline within one week.

### What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested mitigations (optional)
